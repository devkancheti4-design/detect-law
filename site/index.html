How it works

Three signals. One integer law.

No classifier is trained on labelled AI text. The decision is about 325 lines of 32-bit integer C, and its constants are measured on human writing only.

SURPRISE

How predictable is the wording?

A base model (Llama 3.2 1B) measures how much cheaper each word is than it expects. Sampled AI text runs cheap.

CONTRAST

Chosen like a chat model?

A chat-tuned twin (Llama 3.2 1B Instruct) checks whether each word is picked the way assistants pick. Domain vocabulary cancels out.

REPETITION · NEW

Fewer repeats than expected?

AI samplers with a repetition penalty avoid reusing words. The law compares each passage's repeats with what the base model predicts.

LAW

Stops when it's sure. Allows for style.

An anytime-valid test reads 200 tokens at a time and stops when the evidence is decisive. It allows for each writer's steady style, so a distinctive human voice no longer looks like AI.

AI evidence

Statistical evidence of AI generation. Send it to a person for review.

No evidence

Every signal ruled out an AI-sized effect. Not proof of human authorship.

Undecided

No significant AI evidence, but not ruled out either. Most human texts end here. Draw no conclusion.

Install

One command. Then it's yours.

You get a web app, a command line tool, an HTTP API and an MCP server. The two models download once, about 5 GB.

1. Install

pip install "git+https://github.com/devkancheti4-design/detect-law"
Apple siliconRuns on the GPU with MLX
Windows, Linux, Intel MacPyTorch, NVIDIA GPU if present, otherwise CPU
NeedsPython 3.10+ and a C compiler

2. Open the app

detect-law-server

Then open 127.0.0.1:8765. Paste text or drop a .txt, .md, .docx or .pdf file, and pick Careful or Official mode.

Or check files from the terminal

detect-law essay.docx report.pdf        # add --official for the RAID setup

Or call the API

curl -s 127.0.0.1:8765/v1/detect -H 'content-type: application/json' -d '{"text": "Paste the essay here"}'

MCP server

Give your assistant a detector.

Claude and other MCP clients can check pasted text or files on your disk. The check still runs locally.

Claude Code

claude mcp add detect-law -- uvx --from git+https://github.com/devkancheti4-design/detect-law detect-law-mcp

Claude Desktop, Cursor and other clients

{

    "detect-law": {
      "command": "uvx",

Limits

What it can't do.

A verdict is statistical evidence, never proof. Use it to decide what a person should read, not to accuse anyone.

Synonym swappingReplacing words with synonyms hides the surprise signal: 80.8% caught on RAID's official test, against 88 to 92% under most other attacks.
ParaphrasingThe hardest attack: 76.6% caught on RAID's official test, and the app's verdict on paraphrased AI text usually stays undecided.
Base-model samplingAI text sampled from base models without a repetition penalty is the hardest case: 22.5% flagged.
Short texts from frontier modelsClaude-class writing under about 800 words is often undecided. Long documents are much stronger.
AI-polished human writingHuman text heavily rewritten by an AI tool is flagged as AI. It sees AI wording, not where the ideas came from.
Some genres trip it morePoems were wrongly flagged 1.25% of the time, against 0.22% across all genres.
LanguageEnglish only.
Accuracy ceilingTrained commercial classifiers catch more AI text on RAID. Detect Law trades that for zero training, privacy and no cost.
